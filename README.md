# 그림자 도시

플레이 → https://JJH-temp.github.io/my-game/

절차적으로 생성된 3D 도시를 그늘만 밟고 가로질러 반대편 목적지에 도착하는 생존 게임.
해는 시간이 지나면서 하늘을 가로지르고, 그에 따라 건물이 드리우는 그림자의 모양과 방향도
실시간으로 바뀐다. 태양에 노출되면 화상을 입어 체력이 줄어들고, 그늘이나 밤에는 서서히 회복된다.
해가 떠 있는 동안(낮 시간)에만 목적지에 도착해야 클리어로 인정되며, 도착 전에 밤이 오면 실패한다.

## 조작
| 입력 | 동작 |
|---|---|
| W A S D / 방향키 | 이동 (카메라 시점 기준) |
| 마우스 이동 | 화면 가장자리로 커서를 옮기면 그 방향으로 시점이 회전 (클릭 불필요) |
| 휠 | 줌 |
| R | 재시작 (게임 종료 후) |

우측 상단에 해의 위치(하루 진행률)와 목적지까지 거리, 우측 하단에 도시 전체를 보여주는
미니맵이 표시된다. 태양 아래 서 있으면 화면에 붉은 비네트가 나타나며 체력이 빠르게 줄어든다 —
건물이나 가로수의 그늘을 따라 경로를 짜서 목적지에 도달하라.

## 개발
```
npm install
npm run dev
```

Three.js로 제작되었다. 도시/태양/플레이어/미니맵 로직은 `src/game/`에 모듈별로 분리되어 있다.
